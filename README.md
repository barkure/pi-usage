# pi-usage

Run `/usage` to show remaining quota for signed-in Pi providers.

Supported providers:

- DeepSeek
- xAI
- OpenCode Go
- Z.AI
- Z.AI Coding CN
- Kimi For Coding
- Moonshot AI
- Moonshot AI CN

## Install

```bash
pi install git:github.com/barkure/pi-usage
```
